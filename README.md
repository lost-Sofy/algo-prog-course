«ПР1. Ответы на контрольные вопросы»
1) Python интерпретирует каждую строку кода по отдельности, а ошибки обнаруживаются построчно. В отличие от компилируемого языка С#, в нем компилятор просматривает весь код и обнаруживает все ошибки сразу.
2) Dotnet run - позволяет запустить проект одной командой. Сначала она компилирует код, а после его запускает.
3) bin/ - храниться финальный результат работы компилятора, а в obj/ - компилятор хранит промежуточные файлы. Ни одна из папок не отражает изменений в исходном коде, помимо этого они пересоздаются при следующей сборке, и отслеживать их не имеет никакого смысла.
4) git commit - создает снимок изменений проекта в локальном репозитории, git push - пушит его на удаленный репозиторий.
5) Конкатенация соединяет части, а интерполяция позволяет встраивать выражения прямо в строку. Интерполяция зачастую предпочтительнее, потому что она делает код более понятным и выразительным.
6) При делении int на int с дробным результатом - остаток просто отбрасывается, но само число не округляется. Чтобы получить дробный результат нужно обратить хотя бы одну из переменных в double или float. Это называется явное приведение типов.
7) В отличие от обычной переменной значение константы нельзя будет изменить при дальнейшем написании кода. Если попытаться это сделать то программа выдаст ошибку. const очень полезно при использовании неизменяющихся переменных, например: число pi.
8) Инструкции верхнего уровня (top-level statements) позволяют отказаться от некоторых формальностей при написании проекта и сделать код проще. Раньше перед началом программы нужно было обязательно писать: "class Program{ static void Main() }", а функция инструкций верхнего уровня позволила создать исполняемый код непосредственно в корне файла, устранив необходимость упаковки кода в класс или метод.  
*/
